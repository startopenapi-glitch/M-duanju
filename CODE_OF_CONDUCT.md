# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

Be respectful, constructive and welcoming. Harassment, discrimination,
personal attacks and publishing private information are not acceptable.

Maintainers may remove comments, commits or contributions that violate these
standards, and may temporarily or permanently ban participants.

Instances can be reported privately to the maintainers through the repository
contact channel. Reports will be reviewed in good faith and handled
confidentially where possible.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
