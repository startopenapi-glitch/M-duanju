## 技术核对事项（结果见 research.md）

1. 当前读取契约是否能把渠道确认、积分入账、原执行状态分别核实；缺少字段时不得前端推断成功。
2. 项目与 run 的真实状态映射、终态和允许操作；不把方案中的中文解释直接作为新后端枚举。
3. 旧 /settings、/security 及充值链接实际参数与所有调用方，确保合法 run_id 语义不丢失。
4. 现有查询、缓存、身份与草稿设施是否足够；先复用，不默认引入全局状态库。
5. 当前测试库防护、测试脚本、可复现性能基线和 UI 覆盖；不得直接复制别的项目数据库环境变量。

以上代码与契约核对已完成；测试环境实际可用性与性能基线将在实施T01验证，目前不宣称已验证。
